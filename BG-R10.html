Product Name:

BG-R10

Price:

$279

Description:

The Canon BG-R10 is a professional battery grip designed to enhance the performance and handling of select Canon EOS R-series mirrorless cameras. It allows you to use two batteries simultaneously, effectively doubling your shooting time, which is essential for long events like weddings or sports photography. Beyond power, it provides a more comfortable and secure hold when shooting in vertical (portrait) orientation, featuring a secondary shutter release button, multi-controller joystick, and main dials that mimic the camera's layout for seamless operation.


Specifications

  • Compatibility: Designed for Canon EOS R5, R5 C, R6, and R6 Mark II
  • Sensitivity: Not Applicable
  • Auxiliary Input: None
  • Input Terminals: It features a dedicated multi-pin connector that plugs into the camera's battery compartment
  • Weight: Approximately 351g (body only, without batteries)
  • Dimensions: Approximately 143.2 x 109.4 x 81.0 mm

Key Features:

  • Extended Battery Life: Holds up to two LP-E6NH/LP-E6N/LP-E6 batteries, effectively doubling your shooting time.
  • Vertical Handling: Includes a shutter release, main dial, and multi-controller for comfortable vertical (portrait) shooting.
  • Durability: Built to the same weather-sealed standards as the EOS R5 and R6 bodies for dust and moisture resistance.
  • Seamless Integration: Features a dedicated slot to store the camera's battery door, so it doesn't get lost while the grip is attached.
  • Charging Capability: Supports in-camera battery charging via USB Power Adapter PD-E1 (sold separately).
